=== conclusion ===
The min-ct 2 discrepancy is an ORDERING artefact, not a data or
estimator difference: both scripts select the same 921 genes and the same
262 overlapping genes with identical logFC values, but the formal runner
builds the backbone from tapply() (sorted) while the local-kit runner
preserves $candidates appearance order. Ties in the Level-5 mod-z values
make the KS running sum (and hence the permutation null) order-dependent.
=> the single 'epothilone' nominal hit is not even stable to a pure gene
   reordering, on top of the n_perm=1000/3000 instability already recorded.
=> to make any run reproducible, sort the final query vector by gene name
   in BOTH runners before calling audit_connectivity().
